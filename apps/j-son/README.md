# J-SON

형사의 컴퓨터 화면을 브라우저에 재현한 텍스트 추리 게임. J-SUN 안에서 `/j-son` 경로로 서비스된다. 기획은 저장소의 `docs/detective-game-plan.md`에 있다.

사건 하나가 J-SON의 한 편이다. 지금 들어 있는 것은 첫 사건 **J-SON I · 채주빌라 실종 사건(데모)** 하나다. 프롤로그(집주인과 대화)와 1장(경비원과 대화, 인터넷 검색)까지 플레이할 수 있다.

## 이 앱만 띄울 때

```bash
npm install
npm run dev          # http://localhost:3002/j-son
```

DB 없이도 돌아간다. 로그인하지 않은 플레이는 브라우저(localStorage)에만 저장된다. 로그인 저장까지 보려면 J-SUN 루트의 안내대로 DB와 프록시를 띄우고 `npm run db:migrate`를 돌린다.

## 플레이 방식

- 화면 왼쪽은 형사의 모니터, 오른쪽은 수첩이다. 모니터는 **데스크톱**과 **추리판**을 오가고, 수첩의 **단서 노트 / 메모장**은 늘 보인다.
- 글 속의 말은 무엇이든 누를 수 있고, 누르면 단서 노트에 적힌다. 어떤 말이 단서인지는 표시하지 않는다.
- 단서 노트의 말을 빈칸에 끌어다 놓는다(빈칸을 먼저 누르고 말을 눌러도 된다). 빈칸은 추리판 서술, 메일 보내기, 메신저 질문 세 형식으로 나온다.
- 제출하면 맞은 칸 수만 알려 준다. 한두 칸 틀렸을 때는, 그 칸의 단서가 노트에 없으면 "아직 찾지 못한 단서가 있는 것 같아.", 있으면 "지금까지 모은 단서들을 잘 살펴봐야해."가 나온다.
- 추리판을 맞히면 다음 자료가 열리고, 쓴 단서는 단서 보관함에 완성된 문장·출처와 함께 남는다.
- PC 전용이다. 폭 960px 미만에서는 안내만 보인다.

## 사건 쓰기

사건은 코드가 아니라 `cases/<사건 id>/` 폴더의 YAML로 쓴다.

| 파일 | 내용 |
| --- | --- |
| `case.yaml` | 사건 번호(`episode`, 예: J-SON I), 제목, 게임 속 날짜, 장(chapter) 순서와 해금 조건, 결말 |
| `clues.yaml` | 추리판 정답이 되는 단서와 같은 뜻의 말(aliases) |
| `documents.yaml` | 바탕 화면 문서 |
| `messenger.yaml` | 대화 상대와 질문(topic), 답 |
| `web.yaml` | 검색으로 찾는 웹 문서와 검색어 |
| `boards.yaml` | 추리판. `format`은 `statement` · `mail` · `chat` |

본문 표기:

- `[말]`로 감싸면 조사와 떨어져 한 덩어리로 눌린다. 예) `[박채주]가` → "박채주". 감싸지 않은 말도 어절 단위로 눌린다.
- 어떤 말이 단서인지 드러나지 않도록 이름·장소·날짜·물건은 가리지 않고 감싼다.
- 줄 머리 `# `는 제목, `- `는 목록, `; `는 작은 글씨다. `{player}`는 플레이어 이름으로 바뀐다.

해금 조건(`requires`)은 `board:<id>` `topic:<id>` `page:<id>` `chapter:<id>`로 적는다.

`npm run cases:check`가 데이터를 검사한다(빌드와 테스트에서도 돈다). 없는 것을 가리키는 조건, 쓰이지 않는 단서를 잡고, 처음부터 끝까지 풀어 보는 흉내를 내서 "이 추리판의 정답을 그때까지 열린 본문에서 누를 수 있는가", "열리지 않는 자료는 없는가"를 확인한다.

## 구조

- `src/engine/` — 화면과 무관한 게임 규칙. `progress.ts`(해금 계산), `grade.ts`(채점), `view.ts`(지금 열린 범위만 담은 화면 내용), `play.ts`(행동 하나를 처리), `validate.ts`(사건 검증).
- `src/app/api/play` — 게임의 유일한 창구. 화면은 진행 상태를 통째로 보내고, 서버는 그 상태를 다시 따져 열린 범위만 돌려준다. **정답, 단서 목록, 열리지 않은 자료는 브라우저로 나가지 않는다.** 풀었다는 표시는 믿지 않고 적어 낸 답을 매번 다시 채점하므로, 저장된 상태를 고쳐도 다음 자료가 열리지 않는다.
- `src/components/` — 가짜 데스크톱(창, 작업 표시줄, 메신저, 브라우저, 추리판)과 수첩.
- DB 스키마 `j_son`: `progress`(사건별 진행), `submissions`(제출 기록), `completions`(완료 기록). 로비 카드의 "사건 n/m 해결"은 `/j-son/api/summary`가 알려 준다.
- AI는 쓰지 않는다. 정답은 데이터에 고정되어 있다.
